# Gate8

Gate8 is a lightweight web application combining a Python backend with a static HTML/CSS/JavaScript front end. It provides a simple, extensible structure for building a small web service with server-side logic in Python and a responsive HTML UI.

## Tech stack
- Languages: HTML, Python, CSS, JavaScript
- Typical runtimes: Python 3.8+ (Flask / FastAPI / Django-compatible)
- Frontend: static HTML/CSS/JS (served by backend or static host)

## Features
- Small Python-powered API for application logic
- Static HTML/CSS/JS front end (single-page or multi-page)
- Easy local development with virtualenv and a plain static server
